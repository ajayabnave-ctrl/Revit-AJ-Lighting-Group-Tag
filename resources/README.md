# Resources: AJ_Lighting_Group_Tag.rfa

This folder is designated for the Revit tag family file:
`AJ_Lighting_Group_Tag.rfa`

## Requirements for `AJ_Lighting_Group_Tag`

1. **Family Category**: Multi-Category Tag or Lighting Fixture Tag.
2. **Parameters**:
   - Multi-Reference Tag host count (e.g. `(4)`)
   - Type Mark (e.g. `EL_01`)
   - Expected display: `(4) EL_01`
3. **Usage**:
   - When loaded in your Revit project, the **AJ Lighting Group Tag** add-in detects this family automatically.
   - If not loaded, the add-in notifies the user:
     `"AJ_Lighting_Group_Tag was not found in this project. Please load the tag family."`
